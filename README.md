## 📘 Présentation

Ce projet accompagne un cours consacré à :

* **JavaServer Faces 2 (JSF2)**
* **PrimeFaces**
* **PrimeFaces Mobile**

L’objectif est de construire une application complète de **prise de rendez-vous**, déclinée dans plusieurs environnements techniques .

Le document est volontairement pragmatique : il présente uniquement les éléments nécessaires à la construction des applications étudiées .

---

## 🏗️ Applications réalisées

L’application est développée dans les environnements suivants  :

1. **JSF2 / EJB3 / JPA** sur *Glassfish 3.1*
2. **JSF2 / PrimeFaces** (version Ajaxifiée)
3. **JSF2 / PrimeFaces Mobile**
4. Portage de chaque version vers **JSF2 / Spring / JPA** sur *Tomcat 7*

➡️ Au total : **six applications Java EE**.

---

## 🎯 Objectifs pédagogiques

* Comprendre l’architecture JSF2
* Manipuler les composants PrimeFaces
* Intégrer JPA et EJB3
* Comparer une configuration Java EE complète avec une architecture Spring / Tomcat
